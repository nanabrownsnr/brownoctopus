# Brown Octopus 0.5.5

## CPU fallback for CUDA-created snapshots

Embedding snapshots created while CUDA was available can now be loaded by a
CPU-only process. Local, PostgreSQL, and MongoDB snapshot deserialization maps
embeddings to CPU when CUDA is unavailable.

This supports deployments that move Brown Octopus from a GPU to CPU because
of VRAM limits without deleting or rebuilding the existing capability index.

The incremental `OctopusIndex.add()` behavior from 0.5.4 is unchanged.
Retrieval ranking, embedding-provider contracts, sessions, and V3 selection
behavior are unchanged.
