# Brown Octopus 0.5.7

## Fix authenticated MCP discovery

The 0.5.6 MCP header feature now constructs FastMCP's HTTP transport with the
provided ``mcp_headers``. This fixes authenticated discovery for MCP servers
that require request headers.

The headers remain discovery-only: they are not persisted, indexed, logged, or
used by Brown Octopus for tool execution.

## Validation

- Added regression coverage for transport-level header forwarding.
- Full non-external suite passed before release preparation.
