# Brown Octopus 0.5.2

Released 2026-10-06.

## Runtime context configuration

This release clarifies the separation between index management and runtime
session behavior.

`OctopusIndex` manages capability-index creation and updates. Runtime context
limits are configured when obtaining the runtime:

```python
from brown_octopus import OctopusIndex

index = OctopusIndex(index_path="data/indexes/default")
await index.create()

octopus = index.runtime(
    capability_ttl=3,
    active_cap=20,
)
await octopus.initialize()
```

Applications opening an existing index directly can continue to configure the
runtime through `Octopus(...)`:

```python
from brown_octopus import Octopus

octopus = Octopus(
    index_path="data/indexes/default",
    capability_ttl=3,
    active_cap=20,
)
await octopus.initialize()
```

When omitted, the existing defaults remain unchanged:

```text
TTL:        8 turns
Active cap: 30 capabilities
```

Environment variables `OCTOPUS_CAPABILITY_TTL` and `OCTOPUS_ACTIVE_CAP` remain
available for deployment configuration.

## Retrieval compatibility

This release does not change the validated V3 retrieval behavior, including
deterministic spaCy analysis, Qwen embeddings, Min-4, Bounded Max Gap, or the
default TTL and active-cap values.

## Validation

The release candidate is validated with the full non-external test suite before
the tag is published. The tag workflow also runs the supported Windows/Linux
and Python 3.12/3.13 matrix before PyPI publication.
