# Brown Octopus 0.5.6

## Authenticated MCP discovery headers

Brown Octopus 0.5.6 adds request-scoped MCP discovery headers for authenticated
HTTP MCP servers.

```python
from brown_octopus import McpServerSource, OctopusIndex

source = McpServerSource(
    "https://example.com/mcp",
    mcp_headers={"Authorization": f"Bearer {token}"},
)
```

Registry-backed indexes can now use separate credentials for the registry API
and the discovered MCP servers:

```python
index = OctopusIndex.from_mcp_registry(
    registry_url,
    headers=registry_headers,
    mcp_headers=mcp_headers,
)
```

The headers are used only during MCP tool discovery. They are not included in
capability records, persisted index snapshots, or logs. Tool execution remains
under host application control.

## Compatibility

Existing source and registry construction without `mcp_headers` is unchanged.
