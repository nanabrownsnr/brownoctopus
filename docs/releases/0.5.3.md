# Brown Octopus 0.5.3

## Safe index creation on application startup

`OctopusIndex.create()` is now safe to call when an application does not know
whether its configured index store already contains a snapshot.

```python
index = OctopusIndex(
    index_store=index_store,
)

await index.create()
octopus = index.runtime()
await octopus.initialize()
```

The behavior is:

```text
no active snapshot
    → create and publish the initial snapshot

active snapshot exists
    → leave it unchanged
```

To deliberately rebuild an existing index, use:

```python
await index.create(replace=True)
```

`update()` remains the explicit source-synchronization operation. Normal
application restarts can therefore call `create()` safely, or simply call
`initialize()` when index provisioning is handled separately.

This release does not change retrieval ranking, embeddings, session semantics,
or the validated V3 selection behavior.
