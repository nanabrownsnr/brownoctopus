# Brown Octopus 0.5.4

## Incremental capability additions

`OctopusIndex.add()` now adds capabilities to an existing snapshot without
performing a full authoritative synchronization.

```python
await index.create()
await index.add(new_source)
```

The operation discovers only the supplied source, embeds only new or changed
capabilities, and preserves existing capabilities. Multiple sources can be
added in one operation:

```python
await index.add(source_a, source_b)
```

Calling `add()` before `create()` now raises a clear index-readiness error.
Use `update()` when the host intentionally wants to reconcile the complete
configured source universe, including authoritative removals.

The existing snapshot is preserved if discovery or embedding fails. Local,
PostgreSQL, and MongoDB snapshot-store paths are covered by regression tests.

Retrieval ranking, embedding-provider contracts, sessions, and V3 selection
behavior are unchanged.
