# Brown Octopus 0.5.1

Released 2026-10-05.

Brown Octopus 0.5.1 is the first published release of the production-oriented
capability-context API.

## Highlights

- `OctopusIndex` manages capability-index creation and updates.
- `Octopus` loads an existing index and serves runtime retrievals.
- Empty indexes are valid and return empty retrieval results until populated.
- Capability sources support local files, MCP servers, registries, APIs, and
  custom implementations.
- Session state is isolated and can be supplied through a custom
  `SessionStore`.
- Local, HTTP, PostgreSQL/pgvector, and Mongo-backed integrations are exposed
  through optional/provider boundaries without changing the default local
  behavior.
- Model setup remains explicit through `brown-octopus setup-models`; runtime
  initialization does not download models implicitly.
- The managed default embedding dependency is constrained to a NumPy range
  compatible with spaCy and Thinc on Python 3.12 and 3.13.
- README and production documentation describe the validated lifecycle and
  public APIs.

## Frozen retrieval behavior

This release does not change the validated V3 retrieval behavior: deterministic
spaCy intent analysis, capability-oriented retrieval text, Qwen embeddings,
Min-4 plus Bounded Max Gap selection, TTL 8, and active capability cap 30.
