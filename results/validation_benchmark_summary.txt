Brown Octopus Independent Validation Benchmark
===============================================

Status
------
This is the first independently authored validation benchmark after the
50-task development/exploratory benchmark. No production Octopus changes were
made. The frozen hybrid policy is:

selected_k = max(4, bounded_max_gap_k)

with the existing Max Gap calculation, MAX_TOOLS=16, MIN_GAP_PERCENT=2%,
Qwen/Qwen3-Embedding-0.6B, name + description representation, intent
decomposition, merge/dedupe, memory, TTL, and active-cap behavior.

Benchmark methodology
----------------------
The validation set contains 100 tasks, 20 in each existing category:
single capability, capability family, compound, hidden dependency, and
multi-turn. It uses new query wording and new task compositions; no exact query
is duplicated from the 50-task development benchmark.

Queries and required/supporting labels were authored from the canonical tool
names and descriptions before validation retrieval was run. Retrieval rankings
and selector outputs were not used to assign or revise labels. No parameters or
heuristics were selected using this benchmark.

Recommendation
--------------
The hybrid reproduces the exploratory direction on independent data: it
improves required recall and complete-required rate over Fixed-K=4, and its
6.11 tools/turn context is materially smaller than Fixed-K=8's 9.96.

It does not dominate Fixed-K=8: it has lower required recall (0.967 vs 0.979),
lower complete rate (0.958 vs 0.975), and lower supporting recall (0.717 vs
0.783). It also adds unlabeled tools in 15 of 23 expansion intents.

Recommendation: freeze this validation result as evidence supporting further
agent-level comparison, but do not change production Octopus yet. The hybrid
is a credible recall/context middle point, not a proven replacement for either
Fixed-K=4 or Fixed-K=8. Because the required-rank distribution is dominated by
rank-1 cases, use this report as preliminary evidence and author a future
harder validation set independently before making a production decision. Do not
alter this benchmark retroactively. If agent evaluation proceeds, keep all four
policies as separate frozen conditions.
