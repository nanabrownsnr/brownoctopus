============================================

Status
------
This is an exploratory post-Milestone-4 analysis. It must not be treated as
unbiased validation because the hybrid hypothesis was developed after observing
Milestone 3/4 results. Production Octopus was not modified.

6. Recommendation
-----------------
The evidence supports a narrow conclusion: Max Gap contains some useful
expansion information once a safe four-tool floor is imposed. On this frozen
benchmark, the hybrid recovered two Fixed-K=4 required misses and six
supporting misses, while costing less context than Fixed-K=8.

However, this is exploratory and not production validation. Nine expansion
intents added only unlabeled tools, and the hybrid's improvement over Fixed-K=4
was not demonstrated on genuinely unseen tasks. Freeze the rule exactly as
specified for a future preregistered test, but do not change production yet.

Recommended next test before agent evaluation:
1. Create a new, independently authored task set with no overlap in queries or
   tool/task templates with the 50-task benchmark.
2. Freeze the rule and all parameters before inspecting results.
3. Compare Fixed-K=4, Fixed-K=8, Max Gap, and Min-4 + Max Gap.
4. Keep required and supporting labels independent of all retrieval outputs.
5. Only if the hybrid reproduces its recall/context behavior should it be
   considered for downstream agent evaluation.
